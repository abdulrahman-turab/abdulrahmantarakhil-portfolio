# Abdulrahman Tarakhil — Portfolio website

## Run it
1. Extract this ZIP file.
2. Open `index.html` in a browser, or upload the whole folder to a static hosting service.
3. Keep `style.css`, `script.js`, and the `assets` folder beside `index.html`.

## Publish as a public one-click link with GitHub Pages
1. Sign in to GitHub and create a new **public** repository (for example, `my-portfolio`).
2. Upload all files and folders from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. After GitHub publishes it, the site link will be shown in the Pages section and will look like:
   `https://YOUR-USERNAME.github.io/my-portfolio/`

## Before publishing
- The social links are generic placeholders; replace them with your own profile URLs.
- The contact form uses a `mailto:` link and opens the visitor's email app. It does not store messages on a server.
- Project cards are visual placeholders; replace them with your actual project screenshots, descriptions, and URLs.
- The email and profile details were kept from your supplied HTML.
